## 2024-05-30 - Optimize N+1 Query Using inArray Instead of Promise.all
**Learning:** Found a classic N+1 bottleneck in `stock-order.model.ts` where `itemPackageDetails` were queried inside a `Promise.all(rawPlatformItems.map(...))` loop. This means the DB is hit multiple times linearly with the size of the array. The `inArray` operator works well to batch these lookups.
**Action:** Replace `Promise.all` inside mapped loops with a batched DB lookup by extracting unique IDs, executing a single query with `inArray(col, ids)`, and then mapping the results back to the original objects in memory via a Map. Always check for empty ID arrays to avoid Drizzle throwing an error on empty `inArray`.
