## 2024-09-13 - [Type Inference Pitfall with Maps & Sets in Drizzle]
**Learning:** When mapping an array of complex database rows to an array of primitives to feed into `Set` and then `inArray`, passing an implicitly-typed mapped array (e.g., from `results.map`) can result in a TS `unknown[]` type being inferred and passed to `inArray`, triggering a "No overload matches this call" error in Drizzle ORM.
**Action:** Always explicitly type cast primitive values when mapping from Drizzle result objects (e.g., `results.map(row => String(row.id))`) to ensure `inArray` infers a concrete `string[]` or `number[]` signature.
